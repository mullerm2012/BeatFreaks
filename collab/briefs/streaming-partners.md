## Practical partner pitch bundle (owner + ALPHA)

A short BeatFreaks product demo; GPL/Mixxx provenance; Windows/Mac target platforms; MAU/venue projections (honest actual figures, not invented); privacy policy; content security/DRM design; stream entitlement/offline restrictions; no stream ripping; audit logs; performance testing; compliance/legal owner; catalog attribution; support obligations; country rollout; revenue/business model. Request an introduction to *music/DJ platform licensing and partnerships*, not ordinary customer support as if that were guaranteed to approve it. Never submit partnership applications or accept terms without the owner's action.

## C.5 Spotify playlist **metadata-only** bridge

Official references: [Spotify Developer Policy](https://developer.spotify.com/policy); [Feb 2026 migration guide](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide); [playlist docs](https://developer.spotify.com/documentation/web-api/concepts/playlists); [quota mode](https://developer.spotify.com/documentation/web-api/concepts/quota-modes); [rate limits](https://developer.spotify.com/documentation/web-api/concepts/rate-limits).

- Start with a private personal-dev prototype only, user OAuth authorization-code/PKCE, least-privilege scopes and privacy policy. Never scrape, store a Spotify password, or make the Web API return audio for decks.
- Under **February 2026 Development Mode**, user must have Spotify Premium, up to five allowlisted test users, and `GET /playlists/{id}/items` is limited to playlists user **owns or collaborates on**; the older `/tracks` playlist item path was removed. For followed playlists not owned, items may be missing; show an explicit limitation instead of inventing track content. Search has limit 10, not 50.
- Fetch names, artists, album, IDs and Spotify URL only where scopes permit, paginate carefully and handle 429 Retry-After. Match to **locally owned** tracks on artist/title/version and optionally user-confirmed identifiers. Do not copy Spotify catalog audio, album art or features into AI training, don't infer right to play an unmatched song, and never link Spotify to Autopilot streaming without a DJ-specific contract.
- Store minimum metadata for a limited purpose, support disconnect/revoke/cache expiry, display attribution/link back to Spotify where required. **Missing songs → a to-buy list** with links to licensed retail; no automatic downloading/ripping.
- Commercial release is blocked pending approved terms and suitable Spotify partnership/quota approval; a private dev-mode proof-of-concept is not authorization for production or DJ mixing.
