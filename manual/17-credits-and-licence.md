# 17. Credits and licence

## 17.1 Built on Mixxx

BeatFreaks is built on **Mixxx**, the free and open-source DJ software made by
the Mixxx Development Team and many volunteers since 2001. The decks, mixer,
effects, library, analysis, recording, broadcasting, Auto DJ, skins and the
controller mappings in BeatFreaks all come from Mixxx. Thank you to everyone
who has worked on Mixxx.

- Mixxx website: <https://mixxx.org>
- Mixxx source code: <https://github.com/mixxxdj/mixxx>

The controller mappings named in this manual were written by Mixxx
contributors. For example, the Traktor Kontrol S4 MK3 mapping lists its
authors as Be and A. Colombier, and the Traktor Kontrol F1 mapping lists
Ilkka Tuohela. Each mapping's authors are shown in **Preferences →
Controllers → Mapping Info**.

BeatFreaks also uses many other open-source libraries (for example Qt,
PortAudio, Rubber Band, SoundTouch and others). Their licences are included
in the licence text shown in **Help → About**.

## 17.3 Getting the source code

The source code for BeatFreaks, including all changes made for BeatFreaks, is
kept in the BeatFreaks code repository:
<https://github.com/mullerm2012/BeatFreaks>.

If you received BeatFreaks and cannot reach the source code there, ask the
BeatFreaks team for it. Under the GPL you are entitled to it at no extra
charge beyond the program itself.
