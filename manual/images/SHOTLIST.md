# Shot list

Screenshots to capture for the BeatFreaks manual. Every image below is a
placeholder in the manual; none of these files exist yet. Do not invent images.

Rules:

- Capture on Windows 11 at 100% or 125% scaling, default **LateNight** skin,
  window maximised, unless the row says otherwise.
- Use music you have the rights to show (or neutral test tracks). Do not show
  real album covers in the shots.
- Blur your Windows user name wherever a path shows it.
- Save as PNG with the exact file name below into `manual/images/`.
- Rows marked **In development (no screen yet)** cannot be captured today.
  Leave the placeholder until the feature has a real screen. Do not use a
  mock-up that looks like a real screenshot.
- Controller diagrams must be original drawings, not Native Instruments'
  product photos or artwork.
