# BeatFreaks artwork sources

Original vector artwork for BeatFreaks. Editable SVG sources; exported PNG and ICO files are in `../exports/`.

Brand colours: void black #08080A, acid green #C6FF00, hot pink #FF2E88, glitch cyan #00E5FF, deck blue #4DA3FF, orange #FF9A3C.

- **Lettering** in the wordmark, splash and OBS overlay is drawn as vector paths, so it renders the same without any font installed.
- **app-icon-small.svg** is a single bolt for the 16 px and 32 px icon sizes; **app-icon.svg** is used for larger sizes.
- Export sizes: logo-mark 1024×1024, logo-wordmark 2048×640, app-icon 1024×1024, splash and OBS overlay 1920×1080, bg-texture 1024×1024, Stream Deck icons 288×288.
- The OBS overlay is for the master output only, never for cue, library or other private content.

All artwork is original; no third-party logos or assets are used.
