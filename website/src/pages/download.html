Try it safely first

On Windows 11 Pro you can install BeatFreaks in Windows Sandbox, a throwaway copy of Windows that forgets everything when you close it. Controllers may not work inside the sandbox, so test hardware in normal Windows.

  1. Turn on Windows Sandbox.

    Settings → System → Optional features → More Windows features → tick Windows Sandbox, then restart.

  2. Copy the installer in.

    Start Windows Sandbox, then copy the BeatFreaks installer from your PC and paste it into the sandbox window.

  3. Install and look around.

    When you close the sandbox, everything inside it is deleted.
